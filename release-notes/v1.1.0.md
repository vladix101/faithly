# Faithly 1.1.0

Faithly sada postoji i kao **web aplikacija (PWA) za iPhone i Android**, uz Android APK.

## Novo

- **Web / iPhone verzija:** https://faithly.vladetamartinovic10.workers.dev, sa istim izgledom i funkcijama
  (Danas, Biblija, Kalendar, Molitve, Omiljeni, podešavanja). Može da se doda na početni ekran i otvara se
  bez trake pregledača.
- **Dnevni podsetnik na iPhone-u i u web verziji** preko Web Push-a. Stiže i kada je aplikacija zatvorena;
  na iPhone-u radi iz aplikacije dodate na početni ekran (iOS 16.4+).
- Preuzimanje cele Biblije za čitanje bez interneta u web verziji, sa prikazom napretka.
- Izvoz i uvoz omiljenih i beležaka (JSON) u web verziji.
- Poruka „Dostupna je nova verzija” kada se web aplikacija ažurira.

## Android

- Isti application ID i potpisni ključ; nadogradnja preko verzije 1.0.0 čuva omiljene, beleške i istoriju.
- Podsetnici i dalje rade lokalno na telefonu; Android ne dobija web push.
- Interne izmene: zajednički kod za Android i web.

## Obuhvat sadržaja (bez izmena)

- Biblija: Daničić-Karadžić, 66 knjiga, 31.111 stihova (javno vlasništvo). Nekanonske knjige pravoslavnog
  Starog zaveta nisu uključene.
- Kalendar: 2026. i 2027. godina (Vikipedija, CC BY-SA 4.0; pashalija; pravilo posta).
- Molitve: 20 molitava iz Svetog pisma.

## Poznata ograničenja

- Web podsetnici zahtevaju internet i stižu obično u roku od nekoliko minuta od izabranog vremena; tačan
  minut nije garantovan. U web verziji nema podsetnika za praznike i post (postoje u APK-u).
- Pregledač može da obriše podatke sajta (posebno iOS kod aplikacija koje se dugo ne otvaraju): sačuvaj
  rezervnu kopiju omiljenih i beležaka.
- Faithly nije zvanična aplikacija SPC; kalendar prikazuje opšta pravila posta.

## Instalacija

- **iPhone:** otvori link u Safariju → Share / Deli → Add to Home Screen / Dodaj na početni ekran → pokreni
  Faithly → u podešavanjima uključi podsetnik.
- **Android APK:** https://github.com/vladix101/faithly/releases/latest/download/faithly.apk → otvori fajl →
  dozvoli instalaciju iz tog izvora ako sistem traži → instaliraj.
