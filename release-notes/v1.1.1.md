# Faithly 1.1.1

## Ispravke

- Donji meni (Danas, Biblija, Kalendar, Molitve, Omiljeni): natpisi više nisu odsečeni pri dnu – na iPhone-u
  (web aplikacija), na Androidu i pri većem sistemskom fontu. Traka ostavlja i prostor za home indikator.

## Obuhvat sadržaja (bez izmena)

- Biblija: Daničić-Karadžić, 66 knjiga, 31.111 stihova (javno vlasništvo); nekanonske knjige nisu uključene.
- Kalendar: 2026. i 2027. godina.
- Molitve: 20 molitava iz Svetog pisma.

## Poznata ograničenja

Kao u 1.1.0: web podsetnici zahtevaju internet i stižu obično u roku od nekoliko minuta; Faithly nije
zvanična aplikacija SPC.

## Instalacija

- **iPhone / web:** https://faithly.vladetamartinovic10.workers.dev (Safari → Deli → Dodaj na početni ekran).
  Već instalirana web aplikacija prikazuje „Dostupna je nova verzija” → Osveži.
- **Android:** https://github.com/vladix101/faithly/releases/latest/download/faithly.apk – instalira se preko
  postojeće verzije, podaci ostaju.
